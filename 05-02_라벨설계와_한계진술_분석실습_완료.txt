================================================================
실습 1 — 정비 이력에서 학습용 사건과 라벨 창 설계 (약 20~25분)
================================================================

[1] 학습 대상 사건 선별

정비이력 CSV에서 MTR01의 '베어링 고장'을 예측한다고 가정합니다.

고장수리 기록 중 실제 베어링 손상 사건에 해당하는 record_id를 적으세요.

→ R003, R008, R012

점검 / 예방정비 / 개조 기록을 학습용 고장 사건에서 제외해야 하는 이유를
한 문장으로 작성하세요.

→ 점검 / 예방정비 / 개조 기록은 실제 베어링 손상 사건이 아니므로 학습용 고장 사건에서 제외한다.


[2] 사건 시각 결정

각 기록에는 recorded_time, time_type, detected_time이 있습니다.

R003의 학습용 사건 시각으로 어느 값을 사용하는 것이 더 적절한지 적으세요.

선택 시각 :
→ detected_time (2026-07-15 11:20)

이유 :
→ 실제 고장이 발견된 시점으로 작업 시작을 기록한 recorded_time보다 
고장 발생 시점을 더 정확하게 나타내기 때문이다.


[3] 센서 그래프 확인 — Python 사용

05-05_라벨설계_센서데이터.csv에서 다음 그래프를 그리세요.

- x축 : timestamp
- y축 : vibration_rms
- 선 그래프

그래프를 보고 작성하세요.

진동 패턴이 평소와 달라지기 시작하는 시점은
고장 시각보다 대략 몇 시간 전으로 보이나요?

→ 고장 시각보다 약 96시간 전

고장 직전 24시간의 패턴은 그 이전 구간과 비교해 어떤가요?

→ 그 이전 구간보다 진동이 더 빠르게 증가하고 높은 수준을 보여 고장이 크게 진행된 상태로 보인다.

[4] 라벨 창 결정

다음 조건을 사용합니다.

- 고장 직전 24시간은 이미 고장이 크게 진행된 구간으로 보고 학습에서 제외
- 너무 긴 창은 아직 신호가 없는 시점까지 1로 포함할 수 있음

다음 중 가장 적절한 라벨 1 구간을 선택하세요.

[ ] A. 고장 24시간 전 ~ 고장 시각
[O] B. 고장 96시간 전 ~ 고장 24시간 전
[ ] C. 고장 168시간 전 ~ 고장 시각

선택 이유 :
→ 약 96시간 전부터 진동 변화가 나타나며, 
고장 직전 24시간은 이미 고장이 크게 진행된 구간이므로 제외하는 것이 적절하다.

정상 0으로 둘 구간 :
→ 고장 96시간 이전 구간

학습에서 제외할 구간 :
→ 고장 직전 24시간 - 고장 시각

[5] 라벨 누수 확인

센서 CSV의 다음 컬럼 중 모델 입력 특징으로 사용하면 안 되는 컬럼을 찾으세요.

- vibration_rms
- bearing_temp
- motor_current
- load_pct
- run_state
- post_repair_grade
- hours_to_failure

누수 가능 컬럼 :
→ post_repair_grade, hours_to_failure

왜 라벨 누수인지 작성하세요.
→ post_repair_grade는 고장 후 정비 결과에 해당하는 정보이므로 예측 시점에는 알 수 없는 정보다.
→ hours_to_failure는 실제 고장까지 남은 시간을 직접 알려주는 정보이므로
정답 정보를 모델에 미리 제공하는 라벨 누수에 해당한다.

================================================================
실습 2 — 한계를 분류하고 대응 방안 작성 (약 10~15분)
================================================================

05-05_라벨설계_한계사례.csv의 L1~L4를 읽고 아래 표를 채우세요.

한계 유형
- 관측 범위
- 학습 범위
- 사례 수
- 원리적 불가


case_id | 한계 유형 | 왜 제한되는가? | 우선 대응
--------|----------|---------------|----------------
L1	    관측 범위	  펌프 내부를 직접 계측하는 센서가 없어 내부 손상 상태를 충분히 관측할 수 없기 때문이다.	    펌프 내부 상태를 확인할 수 있는 센서나 계측 항목을 추가한다.
L2	    학습 범위	  저속 운전 데이터만 학습하여 고속 운전 조건을 충분히 반영하지 못하기 때문이다.	              고속 운전 조건의 데이터를 추가로 확보하여 학습한다.
L3	    사례 수	동일   고장 사례가 2건뿐이어서 고장 특성을 충분히 학습하기 어렵기 때문이다.	                    동일 고장 사례를 추가로 확보한다.
L4	    원리적 불가	   파손 직전까지 반복 가능한 전조 신호가 없어 사전 예측 자체가 어렵기 때문이다.	              예측보다는 이물 검출이나 보호장치 등 즉시 대응 방식을 적용한다.

[최종 한계 진술]

L1~L4 중 하나를 골라 다음 형식으로 작성하세요.

“현재는 동일 고장 사례가 2건뿐이기 때문에
고장 특성을 충분히 학습하고 예측하는 판단이 제한된다.
따라서 동일 고장 사례를 추가로 확보하는 것을
우선적으로 보완하거나 대안으로 적용한다.”
